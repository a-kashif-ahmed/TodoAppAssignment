# To-Do App — React Native (TypeScript) + Node.js/Express + MongoDB

A full-stack To-Do list app built for the assignment brief: user registration/login,
task CRUD with title/description/date-time/deadline/priority, task completion,
and a bonus smart-sort algorithm that blends deadline urgency, priority, and
scheduled time.

## Project structure

```
project/
├── backend/   # Node.js + Express + TypeScript + MongoDB REST API
└── TodoApp/    # React Native CLI app (TypeScript)
```

Each folder is a standalone project with its own `package.json`. Set up the
backend first, then the mobile app.

## 1. Backend setup

```bash
cd backend
npm install
cp .env.example .env      # then edit .env with your own values
npm run dev                # starts on http://localhost:5000
```

You need a MongoDB instance — either local (`mongod` running on
`mongodb://127.0.0.1:27017`) or a free [MongoDB Atlas](https://www.mongodb.com/atlas)
cluster. Put the connection string in `MONGO_URI` inside `.env`.

Full API reference is in `backend/README.md`.

## 2. Mobile app setup

The `TodoApp/` folder contains the TypeScript source for a **React Native CLI**
project (not Expo), matching the assignment's requirement. Because native
`android/` and `ios/` folders are large, platform-specific, and normally
generated by tooling rather than hand-written, they aren't included here.
Bootstrap them once with the React Native community CLI, then drop in the
provided source:

```bash
# 1. Scaffold a fresh RN CLI project (creates android/ and ios/ folders)
npx @react-native-community/cli init TodoApp --version 0.74.5
cd TodoApp

# 2. Copy this repo's mobile source over the generated skeleton
#    (overwrite App.tsx, package.json, tsconfig.json, babel.config.js,
#    metro.config.js, index.js, app.json, and add the src/ folder)
cp -r ../TodoApp/src ./src
cp ../TodoApp/App.tsx ../TodoApp/package.json ../TodoApp/tsconfig.json \
   ../TodoApp/babel.config.js ../TodoApp/metro.config.js ../TodoApp/index.js \
   ../TodoApp/app.json .

# 3. Install dependencies
npm install

# 4. Set the API base URL (see TodoApp/README.md for emulator vs device notes)
#    Edit src/api/api.ts if needed.

# 5. Run on Android
npx react-native run-android
```

Full details, including Android emulator networking notes, are in
`TodoApp/README.md`.

## Features implemented

- Register / log in with email + password (JWT-based auth, bcrypt hashing)
- Add tasks with title, description, date-time, deadline, and priority
- Mark tasks complete / incomplete
- Delete tasks
- View tasks with status, overdue highlighting
- State managed with React Context + hooks (no Redux needed, kept lightweight)
- **Bonus:** smart sort algorithm mixing deadline urgency + priority + scheduled
  time (implemented on both backend and mobile client)
- **Bonus:** task categories/tags with filter chips
- **Bonus:** status filters (All / Pending / Completed)
- **Bonus:** clean, colorful, custom UI (no default component styling)
