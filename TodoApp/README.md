# To-Do App Mobile (React Native CLI + TypeScript)

## Why no `android/`/`ios/` folders?

This deliverable contains the **app source** (`src/`, `App.tsx`, configs).
Native `android/` and `ios/` project folders are large, machine/OS-specific,
and are normally generated by the React Native CLI itself rather than
hand-authored — committing generated Gradle/Xcode projects here would just
go stale. Bootstrap them once (see root `README.md`) and this source drops
straight in.

## Connecting to the backend

Edit `src/api/api.ts` if your setup differs from the defaults:

- **Android emulator** (default in this project): `http://10.0.2.2:5000/api`
  — `10.0.2.2` is the emulator's alias for your host machine's `localhost`.
- **Physical Android device on the same Wi-Fi**: use your computer's LAN IP,
  e.g. `http://192.168.1.42:5000/api`.
- **iOS simulator**: `http://localhost:5000/api` works directly.

Make sure the backend (`../backend`) is running before you log in/register.

## Running

```bash
npm install
npx react-native run-android
# or
npx react-native run-ios
```

## Project structure

```
src/
├── api/api.ts               # Axios instance, attaches JWT to every request
├── context/AuthContext.tsx  # Auth state (login/register/logout), session persistence
├── navigation/AppNavigator.tsx  # Auth-aware stack navigator
├── screens/
│   ├── LoginScreen.tsx
│   ├── RegisterScreen.tsx
│   ├── TaskListScreen.tsx   # Filters, sort, list, FAB to add
│   ├── AddTaskScreen.tsx
│   └── EditTaskScreen.tsx
├── components/
│   ├── TaskForm.tsx         # Shared form for add/edit
│   ├── TaskItem.tsx         # Task card (checkbox, delete, overdue highlight)
│   └── PriorityBadge.tsx
├── utils/taskSort.ts        # Client-side smart-sort mirror + category helpers
└── types/index.ts           # Shared TS types (Task, User, navigation params)
```

## State management

Auth state lives in `AuthContext` (React Context + `useState`), persisted to
`AsyncStorage` so the session survives app restarts. Task list state is local
to `TaskListScreen`, refetched on focus (`useFocusEffect`) and updated
optimistically on toggle/delete for a snappy feel.

## Notes on the date/time picker

`TaskForm.tsx` uses `@react-native-community/datetimepicker` for selecting
the scheduled date-time and deadline. On Android it opens as a native dialog;
on iOS it renders as an inline spinner.
